# YouTube Digest

YouTube Data API v3에서 지정 주제의 영상을 수집하고, 한국어 영상만 골라 조회수 순으로 보고한다.

## 언제 이 스킬을 쓰는가

- 사용자가 특정 주제의 최근 유튜브 영상을 물어볼 때
- 이전 보고 이후 조회수가 얼마나 변했는지 물어볼 때
- 정기 보고(cron)로 호출될 때

## 실행 전 확인

작업 디렉토리는 `/home/geoheim/projects/youtube-digest` 이다. 다른 폴더에서 실행하지 않는다.

가상환경 Python을 쓴다. `.venv/bin/python`을 직접 지정한다.

## 절차 A — 새로 수집하고 보고

사용자가 "지금 확인해줘", "새로 수집해줘"라고 하거나 cron이 호출한 경우.

1단계, 수집한다. API를 호출하며 약 201 유닛을 쓴다.

```
cd /home/geoheim/projects/youtube-digest
.venv/bin/python scripts/youtube_collect_once.py \
  --query '"AI 에이전트" 만들기' \
  --query 'AI 에이전트 구축 실습' \
  --topic ai-agent \
  --max-results 25
```

2단계, 저장된 원본을 읽어 보고를 만든다. API를 호출하지 않는다.

```
.venv/bin/python scripts/youtube_digest.py --topic ai-agent
```

3단계, 출력 결과를 그대로 사용자에게 전달한다. 내용을 바꾸거나 요약하지 않는다.

## 절차 B — 수집 없이 마지막 결과만 보고

사용자가 "아까 것 다시 보여줘"라고 하거나 할당량을 아껴야 하는 경우.

2단계만 실행한다. 새 API 호출이 없으므로 할당량을 쓰지 않는다.

## 절차 C — 특정 시점과 비교

사용자가 "오늘 아침 8시 것과 비교해줘"라고 한 경우.

먼저 저장된 폴더 목록을 확인한다.

```
ls -1 data/raw/youtube/ai-agent/
```

폴더 이름은 `20260904T121441975762+0900` 형식이며 앞 8자리가 날짜, 다음이 시각이다.

원하는 폴더를 골라 지정한다.

```
.venv/bin/python scripts/youtube_digest.py --topic ai-agent --compare-with 20260904T080000000000+0900
```

기본값은 `--compare-with previous`로 직전 수집과 비교한다.

## 조절 가능한 옵션

`--days 7` 며칠 이내 영상을 볼지. 기본 7일.
`--top 5` 몇 개를 보고할지. 기본 5개.
`--per-channel 2` 같은 채널에서 최대 몇 개까지 뽑을지. 기본 2개.

## 보고 내용 해석

각 영상마다 제목, 채널, 게시 시각(KST), 조회수, 링크가 나온다.

조회수 옆 괄호는 비교 대상 대비 변화다.

- `(+55)` 조회수가 55 늘었다
- `(변화 없음)` 조회수가 같다
- `(신규)` 이전 수집에는 없던 영상이다

"한국어 판정 애매" 목록이 나오면, 한글 비율이 10~30%인 영상이다. 버리지 않고 별도 표시한 것이며 사용자가 직접 판단한다.

## 지켜야 할 것

- `YOUTUBE_API_KEY` 값을 출력하지 않는다.
- `data/raw` 아래 원본 JSON을 수정하거나 삭제하지 않는다.
- 스크립트 출력을 임의로 바꾸지 않는다. 조회수나 날짜를 기억으로 채우지 않는다.
- 영상을 보지 않았으므로 내용의 좋고 나쁨을 평가하지 않는다.
- 수집이 실패하면 오류 메시지를 그대로 보고한다. 원인을 추측하지 않는다.
- 할당량은 하루 10,000 유닛이다. 절차 A는 201 유닛을 쓴다. 하루 수십 번 가능하지만 불필요한 재수집은 하지 않는다.

## 자주 발생하는 상황

수집 결과가 0건이면 검색어가 너무 좁거나 API 오류다. 오류 메시지를 확인한다.

`HTTP 403` 이 나오면 API 키 제한 설정 문제다. Google Cloud Console에서 키에 YouTube Data API v3가 허용되어 있는지 확인해야 한다.

보고에 영어 영상이 섞이면 한글 비율 기준(30%)을 넘긴 경우다. 제목에 한글이 많으면 그럴 수 있다.
